 BastiónTech

**Tu estación. Tu próxima misión.**

BastiónTech es un proyecto de tienda online de periféricos y accesorios para PC. La idea fue crear una página con una estética inspirada en universos de ciencia ficción, combinando tecnología, funcionalidad y diseño.

 Sobre el proyecto

La página está organizada en cinco secciones:

- **Inicio:** una presentación de BastiónTech, las categorías y algunos productos destacados.
- **Catálogo:** teclados, mouse, auriculares y otros accesorios para PC.
- **Preguntas frecuentes:** respuestas sobre compras, medios de pago, envíos, compatibilidad y devoluciones.
- **Contacto:** un espacio para realizar consultas.
- **Sobre nosotros:** la identidad y la propuesta de BastiónTech.

 Tecnologías utilizadas

Para desarrollar el proyecto utilicé HTML y Sass/SCSS para organizar los estilos. También incorporé Bootstrap para la navegación adaptable y Animate.css para agregar animaciones. Git y GitHub me permitieron llevar un seguimiento de los cambios durante el desarrollo.

El sitio cuenta con un diseño adaptable a distintos tamaños de pantalla, metadatos para SEO y textos alternativos en las imágenes.

 Organización de los archivos

El proyecto está organizado con el archivo index.html en la raíz, las otras cuatro páginas dentro de pages/, los archivos SCSS dentro de scss/ y el CSS compilado en styles/. Las imágenes y los demás recursos están guardados en assets/.

Los estilos están separados en archivos parciales para mantener el código organizado y facilitar su modificación.
